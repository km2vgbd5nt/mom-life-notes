# 孩子长得不够高？赶紧看过来！市医院13日将举办儿童生长发育义诊，欢迎带孩子来免费测骨龄

> 更新时间：2026-09-17 (UTC+8)

作为家长，可能常常有这样的困惑：“我家孩子能长多高？”

那么，医生是如何评估孩子的生长潜力呢？其中很重要的一个评价指标就是——骨龄。

为了更好地关注儿童生长发育情况，守护儿童健康成长，恰逢学生放寒假，我院儿科将于1月13日举办“迎新春，助成长，虎虎生威”2022儿童免费骨龄测定义诊活动。

**义诊对象：3-15岁儿童**

1. 孩子身高达到矮小标准（详见以下图片）

2. 孩子一直坐在班级第一排、每年长高不到5厘米或身高明显偏矮；

3. 女孩8周岁前就有乳房发育、男孩9周岁前就有睾丸增大等性早熟现象；

4. 家长对孩子的生长发育有任何不解和疑问，也欢迎亲临义诊活动现场咨询。

**义诊安排**

**活动时间：**2022年1月13日  下午15：00-17:30

**活动项目：**免费骨龄测定（30名）和身高评估等

**义诊专家：**倪敏英副主任医师

**活动地点：**揭阳市人民医院东楼二楼1号诊室

**报名方式**

本次活动采用线上报名，扫描二维码将孩子姓名+出生年月+性别+身高+体重+联系方式发送登记，就诊时间以通知为准。

**专家简介**

倪敏英

揭阳市人民医院儿科副主任医师

毕业于广东医科大学，从事儿科临床工作近20年，熟悉儿科常见病、多发病的诊治，在儿童的生长发育、保健方面有一定的专长。

主要研究方向为儿童保健、生长发育、矮小症、性早熟等。

**出诊时间、地点：**周一至六（东楼二楼儿保诊室）
